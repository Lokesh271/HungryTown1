# HungryTown 🍔

**An AI-powered Restaurant Review and Feedback Analysis Web Application**

## About the Project

HungryTown is a web application that allows users to submit reviews about restaurants. AI analyses customer feedback, identifies issues and provides suggestions to help restaurants improve their services.

## Features

- Submit restaurant reviews.
- Collect customer feedback.
- AI-powered review analysis (planned/in development).
- Identify customer concerns and improvement areas.

## Technologies Used
